      AI settings

      Copy for AI builds a de-identified prompt that you paste into any AI chat yourself — no API key needed, and the app sends nothing to any AI service.

      Direct sending is off by default; while it is off the app never contacts api.x.ai. Get a key at console.x.ai. The key is stored only in this browser's localStorage (never in exported backups) and is sent only to api.x.ai. Anyone using this browser profile could read it — use Clear on shared devices.

      📋 Copy for AI

      One prompt for any AI chat (ChatGPT, Grok, Gemini, Claude…): the instructions, the de-identified case, the transcript and a summary of the previous visit(s), and the request — including suggested changes to the previous formula on follow-ups. Not included: name, contact, date of birth or visit dates (shown as “6 weeks ago”); names, phone numbers, e-mails and dates found in the text are replaced with placeholders. Nothing is sent anywhere — you paste it yourself.
      Send to Grok uses the generated prompt (edits apply to copying only).
